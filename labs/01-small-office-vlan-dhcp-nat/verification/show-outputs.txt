9. Conclusion

The Small Office Network lab demonstrates the implementation of a segmented office network using Cisco Packet Tracer.

The intended configuration provides separate networks for SALES, IT and GUEST departments, alongside a dedicated management VLAN.

DHCP provides automatic IP configuration, Router-on-a-Stick enables communication between VLANs, and NAT Overload allows internal devices to communicate with the public server through the ISP connection.

Final project outcome: All configured network services and connectivity tests are intended to operate successfully.
